メール処理AI プライバシーポリシー

最終更新日: 2026年10月2日

「メール処理AI」は、ネクサスギルドが自社の業務のために運営する個人用ツールです。不特定多数に提供するサービスではありません。本ページは、このツールがGoogleアカウントのデータをどのように扱うかを説明します。

1. 利用するGoogleのデータ

運営者本人および本人が利用を許可したGoogleアカウントのGmailについて、次の範囲にのみアクセスします。

  • メールの読み取り（件名・送信者・本文）
  • ラベルの作成と付与、既読への変更

メールの送信や削除は行いません。

2. 利用目的

受信したメールを分類し、重要なものを運営者本人に通知することだけに使います。広告、第三者へのデータ提供、プロフィールの作成、AIの学習データとしての利用は行いません。

3. データの保管と共有

  • メールの内容は、運営者本人のパソコン内で処理します。分類にはパソコン上で動く言語モデルを使い、メール本文を外部のAIサービスへ送信しません。
  • 通知には、メールの件名と短い要約のみを使い、運営者本人にだけ届けます。
  • 認証トークンは運営者本人のパソコンにのみ保存し、他者と共有しません。
  • 法令に基づく場合を除き、取得したデータを第三者に提供・販売しません。

3の補足: Google APIサービスのユーザーデータに関するポリシー

このツールによるGoogle APIから受け取った情報の利用と他のアプリへの転送は、制限付き使用要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

4. データの削除とアクセス権の取り消し

Googleアカウントのアカウント権限のページから、いつでもこのツールのアクセスを取り消せます。取り消すと、保存されているトークンは無効になります。
